# 一致性契约（CONFORMANCE）—— 可断言、可对拍

> 每条契约必须是**可自动化断言**的。做不到自动化的，不算契约。
> 新实现必须全部通过；旧实现作为对拍基准（baseline）记录实测值。

## 1. 连接与重试

| ID | 契约 | 断言方式 | 关联坑 |
|---|---|---|---|
| C-01 | 任何一次断连后 **30s 内**必然发生至少一次重连尝试 | 单测：注入失败，推进虚拟时钟，断言 `connect` 调用 | Q20 / A3 |
| C-02 | 任何状态跃迁（含失败方向）都产生且仅产生一条事件 | 单测：遍历所有 Phase 转移，断言事件序列 | A3/A5 |
| C-03 | 不存在"既不排下一次也不发终止态"的退出路径 | 单测 + 静态检查（P2）| A3 |
| C-04 | 同一失败序列重放，重试时延可复现（不含未播种随机） | 单测：固定种子 | X5 |

## 7. 对拍台（Conformance Harness）

复用既有资产：`tests/e2e/`（`call-prod`、`call-relay`、`call-prod-proxy`、`call-prod-video`、`call-prod-zombie`）+ 双浏览器 CDP 脚本。

每个场景输出可比对标量：

| 指标 | 目标 |
|---|---|
| 双向 RTP 包数（上下行各自）| 新旧量级一致 |
| 静默秒数（连续无媒体） | **0** |
| 重连时延 P95 | **< 5s** |
| 会议号存活（中途抖动后重入） | **100% 成功** |
| 出声通路数 | **恰好 1** |
| 断言失败数 | 0 |
