# 会议加入诊断与错误页

- 兼容性补强：优先使用浏览器仍提供的旧接口；媒体权限等待有界且晚到的轨道必须释放；基础 WebRTC 不可用或初始化失败时清理服务端成员并显示清晰错误。
- 验收：无设备、拒绝或暂不响应权限不阻塞参会；旧连接状态使用 ICE 状态兜底；可选编码能力缺失不阻塞；旧媒体接口有实际可验证的替代路径；关键 API 不可用不留下幽灵成员。以真实浏览器故障注入、针对性测试和构建验证；不将模拟测试等同于旧版真机覆盖。

- 目标：核查入会异常的浏览器相关性；移除等待麦克风授权的应用横幅，保留错误与重试提示；无效或已结束的会议显示不存在页面。
- 验收：正常会议的加入确认、成员快照、计时不受未完成的麦克风授权阻塞；不存在的会议显示结果页；后台心跳错误不得冒充加入结果；丢失加入回复时有界重试，无法确认时显示连接失败而非无限等待。
- 风险：不同浏览器与真实网络下的故障原因须凭证据判断；不得把超时伪装成会议不存在。
- 验证：本地 Go 服务和独立 Edge/Chrome 实测、入会错误与重试回归、针对性测试、TypeScript 与 ESLint。
