# 会议成员个人音量

## 目标与验收

- AC1：成员列表中可通过扬声器按钮和滑块为其他成员设置 0–200% 的本地收听音量；桌面、触屏和键盘可用，明确提示仅影响自己。
- AC2：每人音量独立、立即生效，默认 100%；暂时静音或音轨更换后继续生效，离开会议后重置。
- AC3：保持现有扬声器设置、自动播放恢复及故障降级行为，避免重复播放或静默绕过个人音量。

## 分工与范围

- 音频实现：`src/core/audio/` 与针对性测试；成员界面：`ParticipantsPanel.tsx`；控制器负责会议集成、验证及审查。
- 原有通话行为、服务端协议与其他人的麦克风发送音量不变。
- 验证：针对音频的自动化测试、TypeScript 检查、浏览器用户路径；独立审查音频和界面。
