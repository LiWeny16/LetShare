# 会议工具栏与本地卡片快捷控制

- 已检查现有底栏、视频墙与媒体状态流程，保留工作区中已有的未提交变更。
- 已实现居中悬浮工具栏、移动端横向滚动及离会菜单；个人卡片提供与原媒体状态机同步的麦克风和摄像头快捷按钮。
- 本地 Edge 与 Chrome 联机验证：卡片鼠标与键盘切换麦克风、摄像头，另一端收到状态变化；控制按钮不触发卡片聚焦；主持人结束会议菜单与取消正常；390px 宽度无整体横向溢出。
- TypeScript、目标 ESLint、30 项会议相关测试和 Vite 生产构建通过；未部署。
- 固定底栏和按钮宽度，离会、成员操作及纪要菜单共用 `MeetingMenu` 样式。先前 Edge/Chrome 验证中，麦克风、摄像头及侧栏状态切换前后底栏位置与宽度一致，离会菜单及键盘关闭正常；后续按用户要求不再自动打开浏览器。
- 统一菜单后的类型检查、目标 ESLint、30 项相关测试和 Vite 生产构建通过；成员与纪要菜单的独立浏览器回归未完成。
