# 会议分组、语言与性能

- 主持人可创建空房间、改名和召回；会议成员可查看服务器同步的房间和成员并自由切换，房间在主会议有效期间保留。
- 房间加入须验证当前会议成员身份；保留原有邀请式分组协议，覆盖主持人切换、父会议生命周期和权限。
- 优化中英文的标签、邀请面板和窄侧栏，提供会议右上角快捷语言切换；减少计时器、音量采样和聊天列表不必要的更新。
- 独立后端审查负责服务端协议和回归；聊天性能 subagent 仅修改聊天面板。主 agent 集成、校验；不自动启动浏览器。
- 验证服务端 WebSocket 业务测试和竞态检查、会议及翻译单测、TypeScript、ESLint；浏览器人工体验需用户自行查看。
